# ForeSports v1

Static corporate website for ForeSports Private Limited.

## Structure

- `index.html` — homepage
- `product.html` — platform overview
- `partners.html` — facility partnership pitch
- `contact.html` — contact
- `privacy.html` — launch privacy placeholder
- `terms.html` — launch terms placeholder
- `css/styles.css` — responsive design system
- `js/main.js` — mobile navigation + dynamic year
- `robots.txt`
- `sitemap.xml`

## Deploy

This is a static site. Upload the contents of this directory to any static host and point `foresports.in` at it.

Recommended launch options:
- Cloudflare Pages
- Netlify
- Vercel static hosting
- GitHub Pages

No build step is required.

## Before launch

1. Replace `hello@foresports.in` if a different public contact address is preferred.
2. Confirm the legal/privacy/terms language with counsel.
3. Add the final favicon and OG image if available.
4. Verify DNS and HTTPS for `foresports.in`.
5. Test all six pages on mobile and desktop.
6. Add analytics only after choosing the provider and updating the privacy policy.
