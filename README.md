# FORE Website v2

Static responsive marketing site for FORE / ForeSports Private Limited.

## Architecture

Three audience paths inspired by modern golf coaching and marketplace UX:
- Golfers
- Coaches
- Facilities

The site remains accurate to the current stage: pre-product, building now, facility-first, with no fabricated live metrics or partner claims.

## Motion system

- Intro loader
- Page transition overlay
- Scroll progress
- IntersectionObserver reveal choreography
- Scroll-linked horizontal journey
- Hero parallax
- Magnetic buttons
- Hover tilt cards
- Image zoom interactions
- Responsive mobile navigation
- Reduced-motion fallback

## Run

Open `index.html` directly or serve the folder with any static server.
